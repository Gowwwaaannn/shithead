# 💩 Head — GitHub Pages test build

Upload `index.html` to a public GitHub repository named `shithead`.

Then in GitHub: Settings → Pages → Source: Deploy from a branch → Branch: main → Folder: /(root) → Save.

Expected address:
https://Gowwwaaannn.github.io/shithead/

This build is an early Safari-playable prototype with bots, pass-and-play, core special-card rules, blind cards and local scoreboard. Online/nearby multiplayer is not yet implemented.
